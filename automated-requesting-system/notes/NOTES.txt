-- Account Security
echo password_hash('yourpassword', PASSWORD_BCRYPT, ['cost' => 12]);

password_hash - This is a built-in PHP function that:
Takes a plain-text password
Returns a secure hashed version of it

BCRYPT is a strong, industry-standard hashing algorithm

cost controls how computationally expensive the hashing is
Higher cost = more secure but slower

Typical values:

10 = default (balanced)
12 = more secure (slower, but still practical)
14+ = very slow (usually unnecessary)

Trust the self-signed cert in your browser
Since XAMPP uses a self-signed cert, any browser will show a warning on first visit to https://localhost.
Chrome/Edge: click "Advanced" → "Proceed to localhost"
To permanently trust it: open C:\xampp\apache\conf\ssl.crt\server.crt → double-click → "Install Certificate" → "Local Machine" → "Trusted Root Certification Authorities"

CSP header in public/index.php
header("Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self'; font-src 'self'; upgrade-insecure-requests;");

Production note
On a real server (cPanel, VPS, etc.), replace the self-signed cert with a free Let's Encrypt cert. The session.cookie_secure line stays exactly the same — no code change needed when you go live.

 ### Docker Backup
```
$date = Get-Date -Format "yyyy-MM-dd"
$backupDir = "backup_$date"
New-Item -ItemType Directory -Path $backupDir

$backupPath = "$PWD\$backupDir"

# Database
docker exec ars_db mariadb-dump -u root -proot arsdb > "$backupDir\arsdb.sql"

# Volumes
docker run --rm -v automated-requesting-system_uploads_data:/data -v "${backupPath}:/backup" alpine tar czf /backup/uploads.tar.gz -C /data .
docker run --rm -v automated-requesting-system_storage_data:/data -v "${backupPath}:/backup" alpine tar czf /backup/storage.tar.gz -C /data .

# App image
docker save automated-requesting-system-app -o "$backupDir\app_image.tar"

Write-Host "Backup done -> $backupDir"

```
- create restore.ps1

```
param([string]$backupDir)

docker load -i "$backupDir\app_image.tar"
docker compose up -d db

docker exec -i ars_db mariadb -u root -proot arsdb < "$backupDir\arsdb.sql"
docker run --rm -v automated-requesting-system_uploads_data:/data -v "${PWD}/$backupDir:/backup" alpine tar xzf /backup/uploads.tar.gz -C /data
docker run --rm -v automated-requesting-system_storage_data:/data -v "${PWD}/$backupDir:/backup" alpine tar xzf /backup/storage.tar.gz -C /data
docker compose up -d

Write-Host "Restore done"
```
